# Лабораторная №5: виртуальные функции и полиморфизм



**Задание.** Иерархия: равносторонний треугольник (база) и производные классы: тетраэдр, правильная треугольная призма, бипирамида. Пользователь вводит количество фигур каждого вида и их параметры; программа выводит сведения о всех фигурах, находит среднюю площадь именно треугольников и фигуру с максимальной площадью.



**Что демонстрирует**

* виртуальные функции и `override`, виртуальный деструктор;
* единый массив указателей на базовый класс (`eqTriangle\*\*`): `print()` и `calculate\_area()` вызываются полиморфно;
* динамическая память.



**Формулы.** Призма: S = 2·S\_осн + 3·a·h, V = S\_осн·h. Бипирамида (6 одинаковых граней): апофема l = √(h² + (a/(2√3))²), S = 6·a·l/2, V = 2·S\_осн·h/3.



**Пример.** Ввод: `1 0 1 0`, сторона треугольника `2`, призма со стороной `2` и высотой `3`. Средняя площадь треугольников 1.73205; максимальная площадь у призмы: поверхность 21.4641, объём 5.19615.



**Известные ограничения**

* треугольники среди прочих фигур определяются по строке названия (`get\_name()`), это хрупкое решение;
* нет проверки ввода;
* наследование объёмных фигур от плоской задано условием; в реальной программе здесь лучше композиция, так как призма не «является» треугольником.
