# C++ OOP labs



Учебные лабораторные работы по ООП на C++ (ГУАП). Идут по нарастающей: от наследования к полиморфизму и абстрактным классам. Во всех трёх фигуры строятся на базе равностороннего треугольника или правильных оснований.



|Работа|Тема|Что в ней|
|-|-|-|
|lab04|Наследование|Треугольник → тетраэдр, динамический массив объектов|
|lab05|Виртуальные функции|Четыре вида фигур, массив указателей на базовый класс|
|lab06|Абстрактный класс|Чисто виртуальные функции, перегрузка `<<`, масштабирование|

## Сборка

Любая работа собирается как консольное приложение в Visual Studio.

Русский текст в консоли выводится через `setlocale(LC\\\\\\\_ALL, "ru")`; на системах не под Windows может потребоваться другая локаль.
