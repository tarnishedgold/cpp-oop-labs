# Лабораторная №6: абстрактный класс и перегрузка `<<`



**Задание.** Абстрактный базовый класс `Figure` (координаты центра основания; чисто виртуальные методы площади боковой поверхности, объёма, масштабирования, вывода; виртуальный деструктор) и два производных: треугольная призма и четырёхугольная пирамида. Вывод сведений через перегрузку `operator<<`, масштабирование в N раз.



**Что демонстрирует**

* абстрактный класс и чисто виртуальные функции, виртуальный деструктор;
* `const`-методы;
* перегрузка `operator<<` через виртуальный `print`;
* координаты вершин основания (треугольник и квадрат) вокруг заданного центра.



**Формулы.** Призма: боковая поверхность 3·a·h, объём √3/4·a²·h. Пирамида: боковая поверхность 4·(a·l/2), где l = √(h² + (a/2)²), объём a²·h/3. Масштабирование умножает сторону и высоту на коэффициент.



**Пример.** Обе фигуры с центром `0 0`, стороной `2`, высотой `3`, коэффициент `2`. Призма: боковая поверхность 18 → 72, объём 5.19615 → 41.5692. Пирамида: 12.6491 → 50.5964, объём 4 → 32.



**Известные ограничения**

* нет проверки ввода (отрицательные размеры, нулевой коэффициент);
* объекты создаются через `new` и удаляются вручную.
