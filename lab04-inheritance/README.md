# Лабораторная №4: наследование



**Задание.** Класс «равносторонний треугольник» (проверка существования, сторона, угол, периметр, площадь, вывод сведений) и производный класс «тетраэдр» (объём, пересчитанная площадь поверхности, свой вывод). Пользователь вводит количество треугольников K и тетраэдров L и их размеры; программа находит среднюю площадь треугольников и тетраэдр с максимальной площадью.



**Что демонстрирует**

* открытое наследование: тетраэдр строится на базе треугольника;
* производный класс скрывает методы базового (методы не виртуальные, вызываются по типу переменной; сравните с лабой 5);
* динамический массив указателей на объекты (`new` / `delete`), ввод количества объектов;
* проверка существования фигуры.



**Формулы.** Площадь треугольника √3/4·a². Тетраэдр с ребром a: площадь поверхности √3·a², объём a³/(6√2).



**Пример.** Ввод: `2 2`, стороны `2 4`, рёбра `1 2`. Средняя площадь треугольников 4.33013; тетраэдр с максимальной площадью: ребро 2, объём 0.942809, площадь поверхности 6.9282.



**Известные ограничения**

* нет проверки ввода (отрицательные значения, не числа);
* при K = 0 или L = 0 результат некорректен (деление на ноль, обращение к пустому массиву).
